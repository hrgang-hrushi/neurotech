1. **Critical — Low confidence can still finish a letter.** Step 2 releases to idle after 16 updates without a confident movement; step 3 treats idle/rest as evidence for the gap clock. A sustained confidence dip therefore releases after 4 seconds and commits after another 3 seconds without confident rest. Separate “released/armed” from “confident rest,” and test uncertainty lasting longer than both timers.

2. **Critical — Nonfinite provenance disappears before the gate.** `StreamPreprocessor.process()` returns only an array, and `load_recording()` discards the preprocessor. After replacing NaNs with zero, `WindowDecider.step(window)` cannot determine which windows contained bad samples. A cumulative `bad_samples` counter cannot identify affected overlapping windows. Carry sample validity through resampling, window extraction and the live ring buffer; test offline/live rejection and recovery after contamination leaves the window.

3. **Critical — The live check lacks an explicit acquisition-time contract.** `EegInlet` buffers up to 30 seconds, while check cues are displayed using the local clock. Scoring by decode/message arrival can attribute buffered pre-cue EEG to a new cue. Define actual displayed onset timestamps, map decision windows to those timestamps, reject stale backlog, and specify the final cue’s slot endpoint. Test delayed pulls and buffered data.

4. **Critical — The clean-rest check can hang indefinitely.** Requiring 120 seconds of clean windows without a deadline means a disconnected stream, unusable baseline or continuously rejected signal never reaches a verdict. Add a wall-clock timeout that records NO-GO with the observed clean duration, and test both no samples and endless rejected windows.

5. **Critical — Simulation conflicts with unconditional verdict gating.** Step 8 makes `run_app` call `choose_model()` and exit without a passing verdict, but the stated backup requires `--simulate` when both models fail. Explicitly bypass model selection for simulation, keep its input isolated from live UDP, and test startup with no model files and with two NO-GO verdicts.

6. **Critical — The fallback cannot qualify through the listed workflow.** Verification calibrates both models but checks only `session-imagined.joblib`. Since missing live results mean NO-GO, a failed imagined model cannot fall back to the real model. Add a real-model check when imagined fails, and verify selection of that independently qualified fallback.

7. **Critical — Counting cues does not guarantee valid folds.** Extracting the current `StratifiedGroupKFold` logic and requiring two cues per class does not establish that every training partition contains every class, especially after gating leaves unequal cue sizes. `evaluate_session()` assigns `predict_proba()` directly into full-width class columns, so a missing class can break evaluation. Construct class-balanced cue partitions or validate each partition explicitly, and test uneven retained windows with at least two cues per class.

8. **Suggestion — Restart handling admits delayed packets from retired runs.** Resetting whenever `run` changes allows an old packet to switch the typer back to the previous run, clear a new sequence and replay an event. Model mismatch validation also happens after state mutation. Validate model/configuration before changing state, ignore retired run IDs, and test interleaved old/new-run packets.

9. **Suggestion — The “ships with package” test only checks the checkout.** `importlib.resources` under the editable installation plus `git check-ignore` does not prove the word list is present in a wheel. Build and inspect or install the wheel in isolation, then read the resource there.
